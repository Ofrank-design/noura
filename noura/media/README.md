# NOURA media guide

All 52 slots are filled with the supplied photography, optimized to 1800 px on the long edge. Each image is referenced by key in `js/imageRegistry.js`, which also holds the alt text and focal point for every photo.

**To replace a photo:** save the new file over the one listed below (same name, JPG) and reload. To use a different name, change `src` in the registry. If a file is missing, a tonal placeholder shows instead of a broken image.

**File names** use lowercase letters and underscores only.
